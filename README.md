# projects-overview

Monorepo of standalone static **project-overview mini-sites**. Each project lives in its own
top-level folder and is deployed to its own subdomain on Coolify (`<project>.67projects.app`).

Each site is a self-contained set of static HTML files (generated by the `project-site` skill:
Overview · Data · Course · Security) served by a tiny nginx container — no build step, no runtime.

## Sites

| Folder        | Subdomain                       |
|---------------|---------------------------------|
| `fastduels/`  | https://fastduels.67projects.app |
| `codehelm/`   | https://codehelm.67projects.app |

## Adding a new site

1. Create a folder `mysite/` with the static files (`index.html`, …) plus a `Dockerfile`:
   ```dockerfile
   FROM nginx:alpine
   COPY . /usr/share/nginx/html/
   EXPOSE 80
   ```
   and a `.dockerignore` containing `Dockerfile` and `.dockerignore`.
2. Commit & push.
3. In Coolify (project **projects-overview**) create a new application from this repo with
   **Base Directory** `/mysite`, **Port** `80`, build pack **dockerfile**, and
   **Domain** `https://mysite.67projects.app`.
4. Add a DNS A record `mysite.67projects.app` → `65.109.60.26` (Cloudflare proxy **OFF**).
